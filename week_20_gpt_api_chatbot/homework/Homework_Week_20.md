# Homework Week 20

**Тема:** GPT API и чат-бот на Python

Ориентир: 180 минут. Самостоятельная работа не входит в 4 аудиторных академических часа.

## 1. Контракт — 15 баллов

Объясните поля messages/choices/usage; добавьте 3 malformed fixtures и тесты parser.

**Подсказка:** Проверяйте пустой content и finish_reason.

## 2. Политика ошибок — 25 баллов

Реализуйте ограниченные повторы с jitter-планом для 429/503; проверьте не более 3 попыток и отсутствие retry для 401/400.

**Подсказка:** В offline тесте передавайте sleep-функцию-заглушку, не ждите реальное время.

## 3. История диалога — 25 баллов

Добавьте reset и максимум 3 полных turns; проверьте, что сбой не меняет историю и сессии двух пользователей не смешиваются.

**Подсказка:** Сначала копия candidate, затем commit после ответа.

## 4. Два API-формата — 20 баллов

Подготовьте конфигурацию запуска Chat/Responses и сопоставление полей. При доступе проведите LIVE_API_LAB, иначе приложите not_run и проверку fixture parser обоих форматов.

**Подсказка:** Реальный usage нельзя заменять числом из synthetic fixture.

## 5. Мини-аудит — 15 баллов

Сдайте README запуска, версии, план измерения стоимости, 5 тестов и объяснение ограничения context window.

**Подсказка:** Последние N сообщений и последние N токенов — разные ограничения.

## Сдача и оценивание

Сдайте заполненный `Homework_Week_XX_Starter.ipynb`, короткий `conclusions.md` (300–500 слов)
и перечисленные в заданиях дополнительные файлы. В имени замените XX номером недели.
Сохраните выполненные outputs; к каждому графику добавьте наблюдение и ограничение вывода.
Не заменяйте TODO решением из практикума без собственного эксперимента.

Итог — 100 баллов: 15 + 25 + 25 + 20 + 15. Внутри каждого задания 60% дают за корректный
результат, 25% — за объяснение, 15% — за воспроизводимость и тесты. Частично рабочее решение
получает пропорциональную оценку; честно обозначенный недоступный облачный этап не считается
выполненным live-тестом. Если учетной записи нет, сдайте обязательный offline-эквивалент и план
live-проверки с ожидаемыми наблюдениями; преподаватель оценивает эти маршруты по одной рубрике.

Контроль перед сдачей: Restart Kernel → Run All, отсутствие секретов, корректные пути,
неизмененные исходные данные, названные источники, явно отделенные измерения от предположений.
