### Связь с практикой

Для каждого примера сначала назовите grain входных и выходных строк. Проверьте, какие записи потеряет INNER JOIN и какие сохранит LEFT JOIN. Подзапросы на с. 45–59 Harvard повторите на локальной SQLite-базе, изменив имена таблиц и колонок по её схеме.

Развёрнутый текст к Harvard: [Relating — Notes](https://cs50.harvard.edu/sql/notes/1/). Исторические рейтинги популярности СУБД и административные слайды не относятся к обязательному материалу. Работа недели использует проверенный синтаксис SQLite.
