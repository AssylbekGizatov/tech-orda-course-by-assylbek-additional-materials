# Homework Week 25

**Тема:** n8n: AI-агент с инструментами

Ориентир: 180 минут. Самостоятельная работа не входит в 4 аудиторных академических часа.

## 1. Контракт tools — 15 баллов

Опишите два инструмента, типы входа, allowed values и результат ошибки. Добавьте 6 negative tests.

**Подсказка:** Инструмент не должен исполнять произвольный текст как код.

## 2. Новый инструмент — 25 баллов

Добавьте read-only duration_minutes для защиты/консультации, реализуйте локально и подготовьте Code Tool node.

**Подсказка:** Четкое описание инструмента помогает agent выбирать его, но тесты все равно нужны.

## 3. End-to-end agent — 25 баллов

Импортируйте workflow и выполните 12 natural-language кейсов при доступе; иначе выполните simulator+JS tools и сдайте план с not_run.

**Подсказка:** Проверяйте фактический вызов tool, а не только правдоподобный текст.

## 4. Memory и failures — 20 баллов

Проверьте 3 session IDs, step limit, неизвестный tool и invalid arguments. Приложите 4 trace.

**Подсказка:** Trace должен показывать наблюдаемые действия и status.

## 5. Наблюдаемость — 15 баллов

Сдайте метрики tool correctness, answer correctness, refusal и latency/usage только если измерены live.

**Подсказка:** Не объявляйте production-ready по одному happy path.

## Сдача и оценивание

Сдайте заполненный `Homework_Week_XX_Starter.ipynb`, короткий `conclusions.md` (300–500 слов)
и перечисленные в заданиях дополнительные файлы. В имени замените XX номером недели.
Сохраните выполненные outputs; к каждому графику добавьте наблюдение и ограничение вывода.
Не заменяйте TODO решением из практикума без собственного эксперимента.

Итог — 100 баллов: 15 + 25 + 25 + 20 + 15. Внутри каждого задания 60% дают за корректный
результат, 25% — за объяснение, 15% — за воспроизводимость и тесты. Частично рабочее решение
получает пропорциональную оценку; честно обозначенный недоступный облачный этап не считается
выполненным live-тестом. Если учетной записи нет, сдайте обязательный offline-эквивалент и план
live-проверки с ожидаемыми наблюдениями; преподаватель оценивает эти маршруты по одной рубрике.

Контроль перед сдачей: Restart Kernel → Run All, отсутствие секретов, корректные пути,
неизмененные исходные данные, названные источники, явно отделенные измерения от предположений.
