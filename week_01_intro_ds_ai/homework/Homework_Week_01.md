# Homework Week 01 — Введение в Data Science и AI

**Оценка самостоятельной работы:** 2–3 астрономических часа; это рекомендация автора практикума,
а не дополнительные контактные часы силлабуса. **Рекомендуемый дедлайн:** 7 дней после занятий недели.
Задание рассчитано на начинающего после лабораторной. Оно развивает материал, а не требует обучения
моделей, которые ещё не разбирались на занятии.

## Что сдавать

- Скопируйте [`Homework_Week_01.ipynb`](Homework_Week_01.ipynb) в `Surname_Week_01.ipynb`.
- Завершите TODO, подпишите графики, добавьте объяснения в Markdown и выполните `Restart Kernel → Run All`.
- В конце укажите 3–5 выводов с числами, одно ограничение анализа и используемые источники/помощь инструментов.
- Представьте notebook с сохранёнными выводами. Большие скриншоты кода не заменяют исполняемые ячейки.
- Не изменяйте исходные файлы `datasets/`: создавайте копии DataFrame и сохраняйте свои результаты отдельно.

## Задания

### 1. Паспорт задачи — 15 баллов

Сформулируйте один описательный и один прогнозный вопрос для поддержки. Для прогнозного укажите пользователя результата, момент прогноза, цель, 3 допустимых признака и один недопустимый будущий признак. Не обучайте модель.

### 2. Контракт исходных данных — 20 баллов

Проверьте число строк, уникальность ticket_id, диапазон satisfaction, пропуски и допустимые каналы. Добавьте минимум 4 понятных assert и объясните, какую ошибку ловит каждый.

### 3. Описание длительности решения — 25 баллов

Для resolution_minutes вычислите n, среднее, медиану, p75, p90, минимум и максимум. Сделайте группировку по category с n и медианой. Сверьте общее среднее со взвешенным средним групп.

### 4. Один график — один вопрос — 20 баллов

Постройте гистограмму длительности решения с медианой и график медиан по категориям. Укажите единицы и источник; сформулируйте два численных наблюдения без причинных утверждений.

### 5. Воспроизводимость и вывод — 20 баллов

Выберите 6 обращений с собственным фиксированным seed; покажите, что повторный выбор совпадает. Сформируйте manifest с seed, версиями и SHA-256 CSV. Напишите 100–150 слов: вывод, ограничение, следующий сбор данных.

## Критерии оценки

| Часть | Максимум |
|---|---:|
| 1. Паспорт задачи | 15 |
| 2. Контракт исходных данных | 20 |
| 3. Описание длительности решения | 25 |
| 4. Один график — один вопрос | 20 |
| 5. Воспроизводимость и вывод | 20 |
| **Итого** | **100** |

Внутри каждой части 60% баллов даются за корректность результата и соблюдение условия,
25% — за воспроизводимость, подписи и проверки, 15% — за объяснение решения своими словами.
Незаполненный TODO не является решением, даже если starter выполняется без ошибок.
Эта рубрика оценивает недельную работу; вклад в итоговую оценку курса определяется общей схемой курса.

## Подсказки без готового решения

- `describe` можно дополнить `quantile`; единицы не исчезают при усреднении.
- Взвешенное среднее использует размеры групп, а не число категорий.
- Для повторения выборки создайте новый генератор с тем же seed.

## Самопроверка перед сдачей

- CSV остался исходным; путь относительный.
- Run All выполняется в чистом kernel.
- Во всех групповых таблицах есть n; в выводах нет обобщения на реальные компании.
