### Связь с практикой

Для вопроса о времени решения обращений из notebook заполните пять этапов процесса: вопрос, единица наблюдения, проверка данных, baseline, вывод. Инструменты Jupyter/Colab/Git изучаются через действия в [практике](../practice/), а не через административные инструкции чужого курса.

Дополнение по Git: [MIT Missing Semester — Version Control](https://missing.csail.mit.edu/2020/version-control/), разделы Git’s data model и Git command-line interface. Это официальный онлайн-конспект, не локальный PDF.
