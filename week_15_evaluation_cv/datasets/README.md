# Данные недели

CSV хранятся локально. Для моделирования используйте только признаки, указанные ниже.

## `imbalanced_synthetic.csv`

Синтетическая редкая положительная категория: `make_classification(n_samples=1000, n_features=8, n_informative=4, n_redundant=2, weights=[0.88,0.12], class_sep=1.1, flip_y=0.02, shuffle=False, random_state=42)`. Все параметры зафиксированы.

**Синтетические данные.** Это учебная генерация, не наблюдения реальных людей или организаций.

Размер: **1000 строк × 10 столбцов**; разделитель — запятая; UTF-8. Пропуски не добавлены. `sample_id` — добавленный локальный номер строки, не исходный идентификатор.

| Столбец | Смысл и допустимые значения |
|---|---|
| `sample_id` | Уникальный целый индекс экспорта; исключить из модели. |
| `x0` | Информативная безразмерная координата. |
| `x1` | Информативная безразмерная координата. |
| `x2` | Информативная безразмерная координата. |
| `x3` | Информативная безразмерная координата. |
| `x4` | Линейная комбинация информативных координат. |
| `x5` | Линейная комбинация информативных координат. |
| `x6` | Случайная шумовая координата. |
| `x7` | Случайная шумовая координата. |
| `target` | Синтетическая метка 0/1; 1 — редкий положительный класс. |

Доля класса 1 близка к 12%, но может отличаться из-за генерации и label noise. Стоимости FP/FN в лабораторной — учебные допущения, не реальные бизнес-данные.

Источники и происхождение:

- <https://scikit-learn.org/stable/modules/generated/sklearn.datasets.make_classification.html>

SHA-256, версия экспортера и схема сохранены в соседнем `*_metadata.json`. Права исходных наборов остаются у их авторов; авторство курса не означает авторство данных.
