## Проверка и восстановление

Локальные размеры и SHA-256 сверены с каталогом, у PDF проверены сигнатура и фактическое число страниц. Репрезентативные страницы просмотрены визуально: формулы и графики отображаются. Проверка структуры всего курса описана в [VALIDATION.md](00_course_admin/VALIDATION.md).

Без сетевых запросов проверить все оригиналы:

```bash
python scripts/restore_resources.py --check
```

Восстановить только отсутствующие файлы отдельной недели:

```bash
python scripts/restore_resources.py --week 9
```

Восстановление использует исходный URL и принимает только байты с записанным SHA-256. Если сайт обновил лекцию или HTML, скрипт сообщает о несовпадении и не подменяет проверенный оригинал. Существующие файлы не перезаписываются.
