# Руководство преподавателя

Этот репозиторий дополняет вашу основную презентацию. Он содержит внешние лекции для выборочного
использования, авторскую практику на русском и задания по каждой из 26 недель. Университеты
не являются авторами этого курса и не подтверждали его качество; авторство внешних материалов
указано отдельно в папках `presentations/`.

## Как подготовить неделю

1. Откройте README недели: проверьте два занятия, необходимые знания и результат обучения.
2. В `presentations/README.md` выберите основной маршрут и указанные страницы. Дополнительные
   колоды могут охватывать существенно больше темы, чем нужно новичку; не планируйте прочитать их целиком.
3. Откройте основной notebook с сохраненными результатами. Перед занятием выполните Restart Kernel → Run All.
4. Проверьте доступность нужного набора зависимостей. Нейросетям в неделе 17 нужны PyTorch и TensorFlow/Keras;
   отдельным главам нужны XGBoost, LightGBM, SHAP и LIME. GPU и сетевое скачивание датасетов не требуются.
5. Заранее прочитайте недельную домашнюю работу, чтобы в занятии подготовить нужные приемы без выдачи решения.

## Нагрузка

Силлабус задает 4 академических часа в неделю (180 минут), всего 104 академических часа (78 обычных часов).
Рабочий план равномерно распределяет общую пропорцию 40/60: 72 минуты теории и 108 минут практики на неделю.
Чтение всех внешних материалов не входит в обязательный контактный объем. Домашняя нагрузка указана
отдельно и является методической оценкой, а не дополнительными часами исходного силлабуса.

Программа широкая для 104 часов. Для начинающей группы приоритет — пройти один полный понятный пример
и объяснить его выводы. Продвинутые части (nested CV, Shapley axiomatics, подробная матричная
производная, оптимизация архитектуры агента) можно разобрать демонстрационно или перенести в чтение.
Сохраняйте цели модуля; не оценивайте новичка за материал, который не был объяснен.

## Стандарт практического занятия

На каждой теме студент должен ответить на вопросы: что является наблюдением, что известно в момент
прогноза, какую величину оцениваем, на каких данных обучаемся и чего не доказывает результат.
Разбор организован как постановка задачи → локальные данные → описательная аналитика → метод →
графики/метрики → проверка → ограничения. Комментарии объясняют смысл операций, не только их синтаксис.

В линейной регрессии и backprop есть собственные реализации и независимые численные проверки.
SQL сверяется с pandas, preprocessing обучается только на train, пороги выбираются до открытия test.
В кластерах различаются переносимые преобразования и трансдуктивные исследования; визуальная
раздельность t-SNE не считается доказательством качества кластера.

## Прогрессия математики

| Когда | Необходимая математика | Как вводить |
|---|---|---|
| 01–03 | Среднее, доля, массив, форма матрицы | Небольшая таблица и ручной расчет |
| 05–08 | Медиана, дисперсия, квантили, корреляция, стандартизация | График и пример чувствительности к выбросу |
| 09–10 | Линейная функция, сумма квадратов, производная, sigmoid | Геометрия ошибки и один шаг градиента |
| 11–14 | Расстояние, impurity, bootstrap, собственные направления | 2D-пример, затем sklearn |
| 15–16 | Условные доли, CV, вклад признака, активация | Confusion matrix вручную, затем локальное объяснение |

| 19–26 | Критерии оценки, состояния, инструменты, стоимость ошибки | Проверяемые контракты и явные эксперименты |

## OpenAI API, Copilot Studio и n8n

В неделях 20–25 находятся два вида практики. Основной notebook выполняет реальную локальную
обработку данных, проверку контрактов, retrieval, SQL и/или явно подписанную симуляцию workflow.
Отдельный vendor lab проводит студента через настоящий сервис. Локальная симуляция не является
доказательством, что агент опубликован в Copilot Studio или workflow импортирован в n8n.

Для API применяются переменные окружения и явный `--live`; случайных платных запросов при Run All нет.
В Copilot Studio потребуются учебное окружение и соответствующий доступ пользователя; в n8n —
совместимая установка и собственные credentials для внешних узлов. Workflow JSON поставляются
неактивными, без секретов. Ссылки на актуальные официальные инструкции находятся рядом.

В Prompt Engineering материал силлабуса о chain-of-thought раскрывается как исследовательский
контекст. Для практических заданий используйте понятный ответ, краткое проверяемое обоснование,
evidence и оценку результата; не требуйте скрытые внутренние рассуждения модели.

## Данные и источники

Учебные бизнес-таблицы явно синтетические. Wine/Diabetes/digits — локальные копии небольших учебных
наборов, источник и преобразования описаны в словарях. Медицинские названия некоторых наборов
используются только для изучения алгоритмов; эти модели не предназначены для медицинских решений.

Внешние PDF сохраняются без смены авторства. Доступность скачивания не означает одинаковую
лицензию для всех колод. В каталоге источников сохранены URL, контрольные суммы и найденные условия.
Материалы с NC-условиями или неустановленным разрешением следует использовать как личные
референсы преподавателя; перед включением в выдачу платного курса проверьте необходимые права.
