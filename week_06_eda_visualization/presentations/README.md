### Связь с практикой

Для одного набора данных постройте гистограмму с двумя вариантами bins, затем boxplot по группам и scatterplot. Обоснуйте, какую информацию сохраняет каждый график. После расчёта Pearson и Spearman исследуйте нелинейный пример и смешение групп в локальном notebook.

Основной маршрут MIT использует формулу Pearson со с. 61. С. 62 содержит авторскую предметную рекомендацию предпочитать регрессию; она не является общим запретом корреляции и не входит в чтение. Pearson инвариантен к положительному линейному изменению единиц обеих переменных; ограничение диапазона наблюдений и смешение групп могут менять наблюдаемую корреляцию. В практике проверены нелинейная связь с малой корреляцией и изменение связи при смешении групп.

Примеры Stanford по старым plotting API служат иллюстрациями. Актуальный код matplotlib/seaborn/Plotly и интерактивный график с локальными данными уже находятся в [практическом notebook](../practice/).
