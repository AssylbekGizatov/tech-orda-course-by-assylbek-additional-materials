# Данные недели

CSV хранятся локально. Для моделирования используйте только признаки, указанные ниже.

## `wine.csv`

Wine Recognition (UCI): результаты химического анализа 178 образцов трёх культиваров из одного региона Италии. Исходные владельцы: M. Forina et al., PARVUS. Экспорт `load_wine(as_frame=True)` без изменения признаков.

**Реальные учебные данные.** CSV — экспорт комплекта scikit-learn; преобразования указаны ниже.

Размер: **178 строк × 15 столбцов**; разделитель — запятая; UTF-8. Пропуски не добавлены. `sample_id` — добавленный локальный номер строки, не исходный идентификатор.

| Столбец | Смысл и допустимые значения |
|---|---|
| `sample_id` | Уникальный целый индекс экспорта; исключить из модели. |
| `alcohol` | Содержание алкоголя, исходная числовая шкала UCI. |
| `malic_acid` | Яблочная кислота. |
| `ash` | Зольность. |
| `alcalinity_of_ash` | Щёлочность золы. |
| `magnesium` | Магний. |
| `total_phenols` | Общее содержание фенолов. |
| `flavanoids` | Флаваноиды. |
| `nonflavanoid_phenols` | Нефлаваноидные фенолы. |
| `proanthocyanins` | Проантоцианины. |
| `color_intensity` | Интенсивность окраски. |
| `hue` | Оттенок. |
| `od280/od315_of_diluted_wines` | Отношение оптических плотностей OD280/OD315. |
| `proline` | Пролин. |
| `target` | Класс культивара 0, 1 или 2; исходные UCI-коды 1–3 сдвинуты scikit-learn на −1. |

Числовые признаки оставлены в исходных шкалах; единицы не дополняются догадками. Это задача распознавания культивара по химическим измерениям, не оценка качества напитка. В неделе 10 бинарная цель `target == 0` создаётся в notebook; исходный `target` затем исключается из X.

Источники и происхождение:

- <https://archive.ics.uci.edu/dataset/109/wine>
- <https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html>

SHA-256, версия экспортера и схема сохранены в соседнем `*_metadata.json`. Права исходных наборов остаются у их авторов; авторство курса не означает авторство данных.

## `moons_synthetic.csv`

Две вложенные дуги с шумом: `make_moons(n_samples=450, noise=0.075, random_state=42)`.

**Синтетические данные.** Это учебная генерация, не наблюдения реальных людей или организаций.

Размер: **450 строк × 4 столбцов**; разделитель — запятая; UTF-8. Пропуски не добавлены. `sample_id` — добавленный локальный номер строки, не исходный идентификатор.

| Столбец | Смысл и допустимые значения |
|---|---|
| `sample_id` | Уникальный целый индекс экспорта; исключить из модели. |
| `x1` | Первая безразмерная координата. |
| `x2` | Вторая безразмерная координата. |
| `target` | Исходная дуга 0/1; скрыть при кластеризации, использовать только для последующего внешнего аудита. |



Источники и происхождение:

- <https://scikit-learn.org/stable/modules/generated/sklearn.datasets.make_moons.html>

SHA-256, версия экспортера и схема сохранены в соседнем `*_metadata.json`. Права исходных наборов остаются у их авторов; авторство курса не означает авторство данных.
