# Данные недели

CSV хранятся локально. Для моделирования используйте только признаки, указанные ниже.

## `digits_8x8.csv`

Optical Recognition of Handwritten Digits, E. Alpaydin / C. Kaynak: scikit-learn включает 1797 изображений из тестовой части исходного UCI набора. Экспорт `load_digits(as_frame=True)`.

**Реальные учебные данные.** CSV — экспорт комплекта scikit-learn; преобразования указаны ниже.

Размер: **1797 строк × 66 столбцов**; разделитель — запятая; UTF-8. Пропуски не добавлены. `sample_id` — добавленный локальный номер строки, не исходный идентификатор.

| Столбец | Смысл и допустимые значения |
|---|---|
| `sample_id` | Уникальный целый индекс экспорта; исключить из модели. |
| `pixel_0_0 … pixel_7_7` | 64 столбца: интенсивность пикселя в строке r и столбце c изображения 8×8, целые 0…16. Порядок — построчно (row-major). |
| `target` | Изображённая цифра, целое 0…9. |

Наша train/validation/test-разбивка выполняется внутри этих 1797 строк и не совпадает с исходным UCI benchmark. Идентификаторы автора почерка здесь отсутствуют: результаты случайной разбивки не доказывают качество на новых авторах. Деление пикселей на 16 опирается на известную схему данных и не обучается на test.

Источники и происхождение:

- <https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits>
- <https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html>

SHA-256, версия экспортера и схема сохранены в соседнем `*_metadata.json`. Права исходных наборов остаются у их авторов; авторство курса не означает авторство данных.
