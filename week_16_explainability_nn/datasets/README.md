# Данные недели

CSV хранятся локально. Для моделирования используйте только признаки, указанные ниже.

## `diabetes_raw.csv`

Набор Diabetes: 442 наблюдения, используемые в примере регрессии Efron, Hastie, Johnstone и Tibshirani (2004). Экспорт `load_diabetes(as_frame=True, scaled=False)`: глобальная нормализация scikit-learn отключена, scaler обучается внутри train/CV.

**Реальные учебные данные.** CSV — экспорт комплекта scikit-learn; преобразования указаны ниже.

Размер: **442 строк × 12 столбцов**; разделитель — запятая; UTF-8. Пропуски не добавлены. `sample_id` — добавленный локальный номер строки, не исходный идентификатор.

| Столбец | Смысл и допустимые значения |
|---|---|
| `sample_id` | Уникальный целый индекс экспорта; исключить из модели. |
| `age` | Возраст в годах, raw-шкала. |
| `sex` | Исходный закодированный пол; не трактовать числовую разницу как меру. |
| `bmi` | Индекс массы тела. |
| `bp` | Среднее артериальное давление, исходная шкала. |
| `s1` | Общий холестерин сыворотки (tc). |
| `s2` | Липопротеины низкой плотности (ldl). |
| `s3` | Липопротеины высокой плотности (hdl). |
| `s4` | Отношение общего холестерина к HDL (tch). |
| `s5` | Показатель ltg; документация описывает его как возможно логарифм триглицеридов. |
| `s6` | Показатель сахара крови (glu). |
| `target` | Численная мера прогрессирования через год; непрерывная цель регрессии, не диагноз. |

Исходные единицы всех лабораторных показателей в карточке scikit-learn не уточнены; их не выдумываем. Набор используется только как компактный учебный benchmark; лабораторные модели не предназначены для решений о здоровье.

Источники и происхождение:
