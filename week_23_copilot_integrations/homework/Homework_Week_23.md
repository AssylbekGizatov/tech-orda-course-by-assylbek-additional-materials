# Homework Week 23

**Тема:** Copilot Studio: интеграции и оценка

Ориентир: 180 минут. Самостоятельная работа не входит в 4 аудиторных академических часа.

## 1. Контракт интеграции — 15 баллов

Опишите knowledge versus tool, вход/выход LookupRequest и источник доверенной identity. Добавьте 4 проверки схемы.

**Подсказка:** Owner из user prompt не является подтвержденным owner.

## 2. Доступ и SQL — 25 баллов

Реализуйте фильтр по owner, валидацию ID и параметризованный запрос. Протестируйте 3 пользователей, чужой ID и injection строку.

**Подсказка:** Не возвращайте полный реестр агенту перед проверкой прав.

## 3. Flow или эквивалент — 25 баллов

При доступе соберите read-only flow и докажите ограничения доступа; иначе расширьте SQLite-эквивалент и приложите карту connector-настроек.

**Подсказка:** Проверяйте maker versus user credentials, а не только текст agent instructions.

## 4. Оценка и публикация — 20 баллов

Составьте 12 acceptance cases и разделите test-pane/канал. Для публикации опишите версию, пользователей и rollback-план; live-статус укажите честно.

**Подсказка:** Один успешный maker-test не подтверждает результат для другого пользователя.

## 5. Отчет — 15 баллов

Представьте таблицу coverage, passed/failed/not_run, минимальный audit log и 3 ограничения.

**Подсказка:** Не считать not_run успешным тестом.

## Сдача и оценивание

Сдайте заполненный `Homework_Week_XX_Starter.ipynb`, короткий `conclusions.md` (300–500 слов)
и перечисленные в заданиях дополнительные файлы. В имени замените XX номером недели.
Сохраните выполненные outputs; к каждому графику добавьте наблюдение и ограничение вывода.
Не заменяйте TODO решением из практикума без собственного эксперимента.

Итог — 100 баллов: 15 + 25 + 25 + 20 + 15. Внутри каждого задания 60% дают за корректный
результат, 25% — за объяснение, 15% — за воспроизводимость и тесты. Частично рабочее решение
получает пропорциональную оценку; честно обозначенный недоступный облачный этап не считается
выполненным live-тестом. Если учетной записи нет, сдайте обязательный offline-эквивалент и план
live-проверки с ожидаемыми наблюдениями; преподаватель оценивает эти маршруты по одной рубрике.

Контроль перед сдачей: Restart Kernel → Run All, отсутствие секретов, корректные пути,
неизмененные исходные данные, названные источники, явно отделенные измерения от предположений.
