## Почему эта карта

Самая близкая из подборки к прикладной разработке приложений с готовыми AI-моделями. Это не полный маршрут исследователя AI. Для начинающего без опыта разработки сначала нужны Python или другой язык, HTTP/API, JSON, Git, тестирование и безопасное хранение ключей.

**Ограничения:** PDF насыщен конкретными сервисами и содержит старые названия API. Не выбирать библиотеку только потому, что она есть на изображении. Дата «2026» на странице не обновляет автоматически PDF 2025 года. Для рабочего кода сверяйтесь с текущей документацией выбранного поставщика.

## На что обратить внимание в обучении

Наши рекомендации, не перевод схемы:

- До сложной архитектуры создать небольшой набор проверочных вопросов и критерии успеха. Сначала сравнить обычный поиск и простой запрос к модели.
- Освоить смысл embedding как векторного представления; для поиска пригодятся скалярное произведение, косинусная близость и понимание ограничений похожести.
- Изучить RAG по [вводному модулю Microsoft](https://learn.microsoft.com/en-us/training/modules/rag-fundamentals/). Поиск по документам не гарантирует правильность ответа.
- Проверять отдельно найденные фрагменты и итоговый ответ: релевантность, опору на источник, полноту. [Документация по оценке RAG](https://learn.microsoft.com/en-us/azure/foundry/concepts/evaluation-evaluators/rag-evaluators).
- До подключения инструментов ограничить права, расходы и действия; протестировать prompt injection и отказ при нехватке данных. Затем добавить мониторинг задержки, ошибок и стоимости.

**Проект для портфолио:** помощник по открытым материалам курса с цитатами. Проверить 30–50 заранее подготовленных вопросов, включая вопросы без ответа в документах; показать ошибки и сравнить результат с простым поиском. Число вопросов здесь учебный ориентир, не достаточная сертификация надёжности.

Обучение большой модели с нуля и fine-tuning не требуются для первого RAG-проекта. Статистика полезна для сравнения версий; глубокая теория обучения нужна по мере перехода к разработке собственных моделей.
