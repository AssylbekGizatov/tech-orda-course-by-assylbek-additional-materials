## Почему эта карта

Удобна для общей ориентации в исследовательско-аналитическом направлении. Есть статистический и экспериментальный акцент, но карта охватывает больше, чем нужно для первой работы с данными. Не стоит воспринимать все ветки как обязательный вступительный экзамен.

**Ограничение для новичка:** изображение ставит большую математическую подготовку перед программированием. В нашем курсе разумнее совмещать базовую математику с небольшими практическими задачами, а не откладывать Python на месяцы.

## Как превратить её в практику

Наши учебные ориентиры, не копия порядка блоков карты:

1. Объяснить среднее, медиану, разброс, выборку и неопределённость на знакомом датасете.
2. Собрать воспроизводимый анализ: вопрос, данные, очистка, графики, ограничения выводов.
3. Построить простой baseline и сравнить его с моделью на отложенных данных. Преобразования обучать только на train, а не на всей таблице. [Документация scikit-learn об утечках](https://scikit-learn.org/stable/common_pitfalls.html).
4. Написать короткую рекомендацию для читателя без технической подготовки. Причинные утверждения не выводить из одной корреляции.

**Проект для портфолио:** исследовать отмены поездок City Trips; отделить наблюдаемые связи от гипотез, сравнить группы и предложить проверяемое следующее действие. Синтетические учебные данные не выдавать за результаты бизнеса.

RAG не является обязательным первым шагом для этой роли. Он пригодится, если выбранный продукт работает с поиском по документам; тогда переходите к [AI Engineer](ai-engineer.md).
