## С чего начать

### 1. Скачайте всю папку курса

На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив. Внутри должны быть `README.md`, `SETUP.md`, файлы `requirements-...` и папки `week_01_...` — `week_26_...`.

Если уже пользуетесь Git:

```bash
git clone https://github.com/AssylbekGizatov/tech-orda-course-by-assylbek-additional-materials.git
cd tech-orda-course-by-assylbek-additional-materials
```

Скачивайте весь репозиторий: одному файлу `.ipynb` нужны данные из соседней папки `datasets/`.

### 2. Подготовьте среду

Для начала нужны **Python 3.12** и базовые библиотеки. GPU и API-ключи для первого занятия не понадобятся. Откройте терминал в корневой папке курса, где лежит этот README.

**Windows · PowerShell**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-core.txt jupyterlab
.\.venv\Scripts\python.exe -m jupyter lab
```

**macOS / Linux · bash или zsh**

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-core.txt jupyterlab
python -m jupyter lab
```

В браузере откроется JupyterLab — среда для работы с ноутбуками. Notebook (`.ipynb`) объединяет объяснения, код и его результаты: таблицы, расчёты и графики.

**Уже работаете в VS Code?** Откройте в нём всю папку курса, установите расширения **Python** и **Jupyter**, откройте нужный `.ipynb` и через **Select Kernel** выберите Python из `.venv`. Библиотеки из `requirements-core.txt` всё равно нужно установить; отдельный интерфейс JupyterLab в этом случае необязателен. Подробнее — в [инструкции VS Code](https://code.visualstudio.com/docs/datascience/jupyter-notebooks).

Подробная инструкция и помощь с ошибками — в [SETUP.md](SETUP.md). Полный набор ML/DL проверялся на **Linux x86_64, Python 3.12.14, CPU**; совместимость всех его пакетов с Windows и macOS не подтверждена.

### 3. Откройте первый практикум

Перейдите в **`week_01_intro_ds_ai → practice → 01_reproducible_data_analysis.ipynb`**.

На первом занятии вы исследуете учебные обращения в службу поддержки: прочитаете таблицу, посчитаете показатели ожидания и построите графики.

- Сначала прочитайте постановку задачи и описание данных.
- Выполняйте ячейки по порядку через **Shift+Enter**.
- После разбора выберите в JupyterLab **Kernel → Restart Kernel and Run All Cells**, чтобы проверить запуск с чистого состояния.
- Сохраняйте свою копию внутри `practice/` или `homework/` соответствующей недели: так сохраняются пути к данным.

В практикумах уже сохранены результаты контрольного запуска. Перезапуск покажет, что получается в вашей среде.

## Как проходить неделю

Удобный порядок: **план недели → фрагменты лекций → разобранная практика → самостоятельная работа**.

| Где искать | Что там находится |
|---|---|
| `week_XX_.../README.md` | Цели, план двух занятий, нужные знания и ссылки на файлы |
| `presentations/` | Дополнительные лекции; в README указаны выбранные страницы и порядок чтения |
| `practice/` | Готовый разбор задачи с кодом, графиками и объяснениями |
| `datasets/` | Данные для этой недели и описание полей |
| `homework/` | Условие домашней работы, критерии и notebook-заготовка с TODO |

Не нужно читать все скачанные лекции целиком. Начните с маршрута в `presentations/README.md`: он отделяет нужные фрагменты от материала для углубления.

### Что такое DATA_DIR и где брать данные?

`DATA_DIR` — переменная Python с путём к папке данных. Например, в первом практикуме:

```python
DATA_DIR = WEEK_DIR / "datasets"
```

Здесь `WEEK_DIR` — папка `week_01_intro_ds_ai`, а `DATA_DIR` указывает на её подпапку `datasets`. Запись `DATA_DIR / "support_tickets.csv"` собирает полный путь к CSV-файлу.

Первый notebook сам ищет папку недели. **Вписывать путь с компьютера преподавателя или скачивать этот CSV отдельно не нужно.** Сохраните структуру репозитория и запускайте ячейки сверху вниз.

Если появился `FileNotFoundError`, проверьте, что архив распакован целиком, папка `datasets/` на месте, а notebook не перенесён отдельно на рабочий стол. Происхождение данных и смысл столбцов описаны в `datasets/README.md` или `DATA_DICTIONARY.md` нужной недели.

## Домашние работы

1. Откройте `homework/Homework_Week_XX.md` нужной недели: там условие, подсказки, ожидаемый результат и рубрика.
2. Откройте notebook-заготовку рядом. Точная ссылка есть в README недели; в названии может быть `starter` или `Starter`.
3. Выполните TODO, проведите эксперимент и напишите выводы своими словами.
4. Перед сдачей перезапустите kernel и выполните все ячейки заново.

Заготовки специально запускаются ещё до решения. **Успешный Run All сам по себе не означает выполненную домашнюю работу** — сверяйтесь с заданием и критериями.

В репозитории есть **26 недельных заданий**. В [схеме оценивания](00_course_admin/ASSESSMENT.md) предложено объединение в **12 оцениваемых сдач** по силлабусу: домашние работы — 40%, промежуточный проект — 20%, финальный проект — 35%, активность — 5%. Проходной результат — не менее 70/100 с обязательной защитой финального проекта.

Промежуточный проект предусмотрен на неделе 13, защита финального — на неделе 26. Конкретные даты и способ отправки работы уточняйте у преподавателя.
