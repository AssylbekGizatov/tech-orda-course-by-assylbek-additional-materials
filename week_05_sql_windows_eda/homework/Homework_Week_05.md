## Задания

### 1. Окно предыдущих семи дней — 25 баллов

SQL-запросом рассчитайте среднюю выручку предыдущих 7 строк без текущего дня для каждого магазина. Для первого дня результат должен быть NULL. Объясните разницу с окном, включающим текущий день, если результат нужен как признак прогноза.

### 2. Рейтинг и совпадения — 20 баллов

Найдите 3 дня с максимальной выручкой каждого магазина через ROW_NUMBER с детерминированным tie-breaker. На маленькой таблице с равными суммами сравните ROW_NUMBER, RANK и DENSE_RANK.

### 3. Независимая сверка окон — 20 баллов

По CSV воспроизведите семидневное прошлое окно и top-3 в pandas. Проверьте все значения, порядок и начальные NaN; отдельно убедитесь, что окна не смешивают магазины.

### 4. Распределение среднего чека — 20 баллов

Для каждого магазина опишите дневной средний чек: n, mean, median, sample std, IQR. Постройте ECDF двух магазинов на общей шкале. Не выдавайте 35 дневных средних за распределение чеков отдельных заказов.

### 5. Акции и ограничения — 15 баллов

Сравните дни с акцией и без по числу дней, числу заказов и выручке на магазин-день. Напишите 150 слов: наблюдение с числами, два возможных смешивающих фактора и какие данные нужны для причинного вывода.

## Подсказки без готового решения

- SQL frame `... AND 1 PRECEDING` исключает текущую строку.
- В pandas сначала shift внутри группы, затем rolling.
- Для одинаковых значений добавьте дату как tie-breaker только в ROW_NUMBER.
- ECDF по дням и ECDF по заказам отвечают на разные вопросы.
