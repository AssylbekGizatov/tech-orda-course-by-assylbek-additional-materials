### Уточнения для корректного чтения

В CMU на с. 86–88 `ROW_NUMBER` без `ORDER BY` внутри окна иллюстрирует разбиение на группы. Для воспроизводимого ранжирования задайте сортировку внутри `OVER` и ключ для разрешения совпадений. Внешний `ORDER BY` отвечает за порядок вывода. В нашей практике дополнительно разобраны `LAG`, `DENSE_RANK`, явные `ROWS`-границы, накопительный итог и сверка всех результатов с pandas. Справочник: [SQLite — Window Functions](https://sqlite.org/windowfunctions.html).

На с. 6 MIT в формуле выборочной дисперсии центр записан символом μ. В практике явно используется выборочное среднее x̄ и деление на n−1 (`ddof=1`); для дисперсии данного набора как полной совокупности — n (`ddof=0`). Сравнивая числа, сначала согласуйте определение.

В PDF Berkeley EDA Continued на титуле осталось «Lecture 5»; официальный каталог относит файл к занятию 6. Нумерация в маршруте всегда означает страницу PDF.
