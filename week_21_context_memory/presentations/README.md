## Университетские презентации

### [Stanford_CME295_RAG_Agents.pdf](Stanford_CME295_RAG_Agents.pdf)

**CME295 Lecture 7: Agentic LLMs, RAG and Function Calling (Fall 2025)**  
Stanford University; Afshine Amidi and Shervine Amidi. Полный файл: **151 стр.**

**Выбранный фрагмент:** PDF-страницы 11, 14, 16, 20–21, 24–28, 30–35, 43, 45, 47, 63, 67, 73–76: причины RAG, подготовка базы/chunks, semantic/keyword/hybrid retrieval, ranking и Recall@k/Precision@k.  
**Время:** около 30 мин. **Уровень:** Выборка для начинающих после TF-IDF; полный CME295 углублённый. NDCG и продвинутый reranking необязательны.

**Связь с неделей:** Первое занятие: локальный retrieval и независимая оценка поиска. На 74–75 вручную посчитайте Recall@k и Precision@k для одного запроса.

Используется опубликованная архивная лекция Fall2025. В учебной CPU-практике retrieval — локальный TF-IDF, а не hosted vector store. Память диалога, контекстное окно и база знаний — разные состояния; актуальная реализация OpenAI описана в двух соседних snapshots.
