### Технические оговорки

Это архивные учебные слайды. В MIT Functions с. 21–24 встречается синтаксис печати Python 2; эти страницы исключены из основного маршрута. В текущей практике используется Python 3. В Stanford встречаются типографские кавычки и исторические числа времени исполнения: копировать команды удобнее из проверенного notebook, а скорость измерять на своём компьютере.

Перед каждым NumPy-примером предскажите shape и проверьте две строки результата вручную. Такая проверка особенно полезна для broadcasting и отличия `*` от `@`.
